Анализ и автоматизация Excel-отчётов с помощью Power Query

О проекте

Проект посвящён автоматизации обработки большого количества однотипных Excel-отчётов.
Изначально данные хранились в отдельных Excel-файлах. Для объединения и обработки данных использован Power Query.

Цель проекта — автоматизировать загрузку, очистку, объединение и анализ данных, чтобы не выполнять эти операции вручную для каждого отчёта.

Что сделано:

- Объединены данные из 30 Excel-файлов
- Автоматизирована загрузка данных из папки
- Выполнена очистка и преобразование данных
- Приведены данные к единому формату
- Добавлены необходимые вычисляемые столбцы
- Созданы сводные таблицы
- Создан лист «Аналитика»
- Настроено обновление данных через Power Query

Используемые инструменты:

- Microsoft Excel
- Power Query
- Сводные таблицы
- Формулы Excel

Результат:

После добавления новых файлов в исходную папку данные можно обновить в Excel, не выполняя обработку вручную.

Проект демонстрирует навыки автоматизации работы с Excel-данными и подготовки данных для последующего анализа.

Структура проекта:
- `Project.xlsx` — основной файл проекта
- `Source/` — исходные Excel-файлы
- `README.md` — описание проекта
